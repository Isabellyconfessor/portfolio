# 💻 Meu Portfólio Pessoal

Este é o meu cartão de visitas no mundo do desenvolvimento. Um projeto criado para apresentar minha trajetória, habilidades técnicas e os projetos que venho desenvolvendo na minha transição de carreira para o Front-end.

O projeto foi desenvolvido como parte do desafio do programa **Oracle Next Education (ONE)** em parceria com a **Alura**.

---

## 🚀 Tecnologias e Ferramentas
Neste projeto, foquei em aplicar as melhores práticas de desenvolvimento web:

* **HTML5:** Estruturação semântica para melhor acessibilidade e SEO.
* **CSS3:** Estilização avançada utilizando **Flexbox** para o layout e **Media Queries** para garantir a responsividade.
* **JavaScript:** Pequenas manipulações no DOM (como a atualização automática do ano no rodapé).
* **Mobile First:** O site foi pensado primeiro para dispositivos móveis e depois adaptado para desktop.

---

## 🎨 O que eu pratiquei
- [x] Semântica HTML.
- [x] Posicionamento de elementos com Flexbox.
- [x] Design responsivo e adaptação para diferentes telas.
- [x] Manipulação básica de DOM com JS.
